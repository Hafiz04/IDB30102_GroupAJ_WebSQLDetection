# Dataset Source Information

## Dataset Name

SQL Injection Sample Dataset

---

## Dataset Source

This dataset was manually prepared by the research group for preliminary SQL Injection detection prototype development.

The dataset contains simulated SQL query samples consisting of normal queries and SQL Injection attack payloads.

---

## Purpose of Dataset

The dataset is used to support the development of the proposed Ensemble Learning framework.

The main purposes include:

- Testing SQL query preprocessing techniques
- Applying TF-IDF feature extraction
- Training machine learning classifiers
- Evaluating SQL Injection classification capability

---

## Dataset Categories

The dataset contains:

| Category | Label |
|---|---|
| Normal SQL Query | 0 |
| SQL Injection Attack | 1 |

---

## Future Dataset Integration

For future research improvement, larger publicly available datasets may be integrated, including:

- HTTP CSIC 2010 Dataset
- Kaggle SQL Injection Dataset

These datasets can provide more diverse SQL Injection patterns for further evaluation.

---

## Data Privacy Statement

This dataset does not contain confidential, private, or sensitive information.

All SQL query samples are created for academic research and cybersecurity testing purposes only.
